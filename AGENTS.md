# Project skills

This project uses React/TypeScript for the upload UI and Python for PDF timetable parsing. Relevant local skills:

- `pdf`: inspect the source timetable layout and extracted tables before changing parser rules.
- `python-testing`: cover parser edge cases with unit tests and source-PDF regressions.
- `frontend-patterns`: keep upload conversion consistent with shared frontend utilities.
- `frontend-design`: keep the gratitude activity visually distinctive while preserving its existing interaction model.
- `e2e-testing`: use browser interaction tests when upload flow or UI behavior changes.
- `tdd-workflow`: add and run a focused regression before changing frontend behavior or structure.
- `imagegen`: create project-bound raster artwork when visual assets are part of the requested experience.

For timetable changes, preserve the intentional handling of `其他课程`. Image timetable OCR and horizontal PDF parsing are separate paths from `pdf_plumber_parser.py`.
