## SSE 流式输出链路

```mermaid
sequenceDiagram
    participant B as 浏览器
    participant E as Express :3001
    participant D as Dify :5001
    participant AI as DeepSeek V4

    B->>E: POST /api/ai/counsel/stream
    E->>E: JWT 验证 + 保存用户消息
    E->>E: 查用户画像 + 计算教学周
    E->>D: fetch POST /v1/chat-messages (stream)
    Note over E,D: conversation_id 多轮记忆<br/>inputs: 画像+日期+教学周
    D->>D: 知识库检索 (Rerank) + Tavily
    D->>AI: 构建 Prompt + 上下文
    AI-->>D: SSE chunk 1
    AI-->>D: SSE chunk 2
    AI-->>D: SSE chunk ...
    D-->>E: data: {"answer": "..."}
    E-->>B: data: {"chunk": "..."}
    Note over B: 渲染 Markdown<br/>实时显示
```
